Variables usadas en el análisis

La base de datos bikedata contiene 8645.000 observaciones horarias del sistema Capital Bikeshare. Para este ejercicio seleccionamos las siguientes variables:

  • high_demand: indicador construido con el cuartil superior de bikers.

    • 0 = demanda baja o media.
    • 1 = demanda superior al percentil 75. Es nuestra variable dependiente binaria en el Modelo Lineal de Probabilidad (LPM).

  • temp: temperatura normalizada entre 0 y 1. Permite estudiar cómo cambia la demanda a lo largo del rango térmico observado.

  • bikers: número de usuarios de bicicletas en la hora. Es la variable continua que usamos en la regresión lineal clásica.

  • hum: humedad relativa normalizada entre 0 y 1. La usamos en interacción con temperatura para evaluar si el gradiente térmico cambia según la humedad.
