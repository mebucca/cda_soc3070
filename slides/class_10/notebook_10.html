1. El Modelo Logístico

En esta práctica trabajamos con la base bikedata para predecir si un hora tiene demanda alta (high_demand = 1). Consideramos dos predictores:

  • temp: temperatura normalizada entre 0 y 1.
  • hum: humedad relativa normalizada entre 0 y 1.

La regresión logística modela la probabilidad de un evento binario en función de covariables. Con el link logit transformamos la probabilidad:

\[ \text{logit}(p_i) = \ln \frac{p_i}{1-p_i} = \beta_0 + \beta_1 temp_i + \beta_2 hum_i \]

Code 
> # Cargar y preparar los datos
> source("../_shared/bikeshare.R")
> course <- use_course_data("juventus")
> bikedata <- course$data
> 
> # Ajustar modelo logístico
> logit_model <- glm(high_demand ~ temp + hum, data = bikedata, family = binomial(link = "logit"))
> summary(logit_model)

2. Efecto Lineal sobre el Logit

En la escala del logit, la relación es lineal y constante:

Cada coeficiente representa el cambio en el logit ante un aumento de una unidad en el predictor, manteniendo fijo el otro. Como temp y hum están normalizadas, conviene complementar esta escala con odds ratios y efectos sobre probabilidades.

Code 
> # Grilla para predicciones con hum promedio
> newdata <- tibble(
+   temp = seq(min(bikedata$temp), max(bikedata$temp), length.out = 100),
+   hum = mean(bikedata$hum)
+ )
> 
> newdata$logit_pred <- predict(logit_model, newdata = newdata, type = "link")
> 
> ggplot(newdata, aes(x = temp, y = logit_pred)) +
+   geom_line(color = palette[["series-2"]], linewidth = 1.3) +
+   labs(
+     title = "Efecto de 'temp' sobre el Logit",
+     subtitle = "Manteniendo la humedad constante en su media",
+     x = "Temperatura normalizada",

4. Efecto sobre la Probabilidad

En la escala de probabilidad, los efectos no son constantes:

  • Más fuertes cerca de \(p=0.5\).
  • Más débiles en los extremos (cerca de 0 o 1).
Code 
> # Curvas sigmoides para distintos niveles de hum
> hum_values <- c(
+   quantile(bikedata$hum, 0.25, na.rm = TRUE),
+   mean(bikedata$hum, na.rm = TRUE),
+   quantile(bikedata$hum, 0.75, na.rm = TRUE)
+ )
> data_plot <- expand.grid(
+   temp = seq(min(bikedata$temp), max(bikedata$temp), length.out = 100),
+   hum = hum_values
+ )
> 
> data_plot$prob_pred <- predict(logit_model, newdata = data_plot, type = "response")
> 
> ggplot(data_plot, aes(x = temp, y = prob_pred, color = factor(hum))) +
+   geom_line(linewidth = 1.2) +
+   labs(
+     title = "Efecto sobre la Probabilidad",
+     subtitle = "Curvas sigmoides para distintos niveles de humedad",
+     x = "Temperatura normalizada",
+     y = "Probabilidad de demanda alta",
+     color = "Humedad normalizada"
+   ) +
+   theme_julia()

5. Efectos Marginales

En los modelos logísticos, los coeficientes (β) no se interpretan directamente en términos de probabilidades, sino en la escala del logit. Para facilitar la interpretación, usamos efectos marginales, que traducen esos coeficientes en cambios en la probabilidad de ocurrencia del evento (aquí, tener demanda alta).

Los efectos marginales muestran cómo varía la probabilidad de éxito (high_demand = 1) frente a un cambio pequeño en una variable explicativa, manteniendo las demás constantes.

Existen tres maneras habituales de calcularlos:

  • AME (Average Marginal Effects): promedio de los efectos marginales individuales en toda la muestra. Responde a: “en promedio, ¿cómo cambia la probabilidad si todos aumentaran en una unidad su predictor?”
  • MEM (Marginal Effects at the Mean): evalúa los efectos marginales en el individuo promedio, es decir, tomando los valores medios de los predictores.
  • MER (Marginal Effects at Representative Values): muestra los efectos en casos concretos, definidos por combinaciones específicas de las variables.

AME

Code 
> avg_slopes(logit_model)
#> 
#>  Term Estimate Std. Error     z Pr(>|z|)     S  2.500 % 97.500 %
#>  hum    -0.371     0.021 -17.800   <0.001 232.100 -0.412 -0.330
#>  temp    0.716     0.019  37.000   <0.001 993.600  0.678  0.754
#> 
#> Type: response
#> Comparison: dY/dX

Interpretación: la columna estimate expresa el cambio promedio en probabilidad ante una unidad adicional del predictor. El signo indica la dirección y el intervalo de confianza cuantifica la incertidumbre.

👉 El AME ofrece una visión global, útil cuando queremos un resumen simple del efecto promedio.

MEM

Code 
> vm <- expand.grid(temp = mean(bikedata$temp,na.rm=T), hum = mean(bikedata$hum,na.rm=T))
> mem <- slopes(logit_model, newdata = vm) %>%
+   select(term, estimate, std.error, conf.low, conf.high, p.value) 
> 
> bind_cols(vm, mem)
#>     temp    hum term estimate std.error conf.low conf.high
#> 1 0.489 0.643  hum  -0.396   0.023  -0.442   -0.350
#> 2 0.489 0.643 temp   0.762   0.024   0.716    0.809
#>                                                                                                                                                                                                                                   p.value
#> 1 0.000
#> 2 0.000

Interpretación:

La tabla evalúa ambos efectos en una hora hipotética con temperatura y humedad medias.

El MEM es intuitivo porque se interpreta en un caso concreto. Sin embargo, puede ser engañoso si la combinación promedio de covariables no representa una hora realmente observada.

MER

Code 
> vr <- expand.grid(
+   temp = quantile(bikedata$temp, c(0.25, 0.75), na.rm = TRUE),
+   hum = quantile(bikedata$hum, c(0.25, 0.75), na.rm = TRUE)
+ )
> mer <- slopes(logit_model, newdata = vr) %>%
+   select(temp, hum, term, estimate, std.error, conf.low, conf.high, p.value) 
> 
> mer
#> 
#>  Term Estimate Std. Error Pr(>|z|)  2.500 % 97.500 %
#>  hum    -0.302    0.024   <0.001 -0.349 -0.256
#>  hum    -0.596    0.037   <0.001 -0.668 -0.525
#>  hum    -0.165    0.009   <0.001 -0.182 -0.148
#>  hum    -0.484    0.024   <0.001 -0.531 -0.438
#>  temp    0.583    0.014   <0.001  0.556  0.610
#>  temp    1.150    0.040   <0.001  1.072  1.227
#>  temp    0.319    0.011   <0.001  0.297  0.340
#>  temp    0.933    0.040   <0.001  0.854  1.012

Interpretación:

Los cuatro escenarios cruzan los cuartiles 25 y 75 de temperatura y humedad. Así podemos comparar el mismo cambio bajo condiciones frescas/cálidas y secas/húmedas sin extrapolar fuera del soporte observado.

👉 El MER es útil porque permite explorar cómo cambian los efectos en situaciones representativas o extremas, mostrando la heterogeneidad de los efectos.

6. Conclusión

  • En la escala logit, los efectos son lineales y fáciles de calcular, pero difíciles de interpretar.

  • En la escala de odds, se interpretan como multiplicadores, lo cual es más informativo que el logit, pero aún abstracto.

  • En la escala de probabilidad, los efectos no son constantes: dependen del nivel de las covariables. Por eso es necesario mirar AME, MEM y MER para obtener una imagen completa.

  • Cada medida responde a una pregunta distinta:

    • AME: visión promedio global.
    • MEM: visión puntual en el “individuo promedio”.
    • MER: visión contextualizada en escenarios concretos.

En resumen, no existe una única interpretación de los efectos marginales. La escala (logit, odds, probabilidad) y el escenario (promedio, promedio de covariables, o casos representativos) condicionan la lectura. Entender estas diferencias es clave para comunicar correctamente los resultados.
